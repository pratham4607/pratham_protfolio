# Pratham S — Portfolio

A responsive, minimal portfolio built with plain HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Customize
- Replace `assets/profile-photo.jpg` with another portrait (keep the same filename, or update its path in `index.html`).
- Update text and add real project entries in `index.html`.
- Edit colors, spacing, and responsive styles in `styles.css`.

## Contact form
The form validates the fields in the browser and prepares an email using the visitor's default email app (`mailto:`). It does not submit to a server. For server-side delivery, connect it to a form backend or your own endpoint.
